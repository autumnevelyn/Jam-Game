# <u>[CountBound](https://arthreena.itch.io/countbound)</u>
### a *GMTK jam 2026* game by [arthreena](https://arthreena.itch.io/) & [enny's](https://ennys.itch.io/)
jam entry for v1.0: https://itch.io/jam/gmtk-jam-2026/rate/4816672

### State of the game
as this game was developped during a jam, there were lot's of compromises and simplifications in game ui, logic, mechanics, content... just the overall vision.
there is known, and certainly many unknown bugs and issues.
the game project is a mess, contains tons of dead code and would benefit from a cleanup. that being said i think the game turned up nicely!
and who knows, maybe will get updates in the future

### Controls
- movement: <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd>
- slash: <kbd>LMB</kbd>
